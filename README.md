# ⚽ Real-Time Ball Tracking using YOLO, OpenCV, Interpolation & Python

Build a complete **Real-Time Ball Tracking System** using **YOLO**, **OpenCV**, **Pandas**, and **Python**. This project demonstrates an end-to-end computer vision pipeline that detects a fast-moving sports ball, caches detections for faster execution, fills missing detections using linear interpolation, and visualizes smooth tracking results in real time.

Whether you're working on **football analytics**, **cricket ball tracking**, **tennis analysis**, or other **sports AI** applications, this project provides a practical foundation for robust object tracking.

## 🚀 Features

* ⚽ Real-time ball detection using a custom YOLO model
* 🎥 Video processing with OpenCV
* 💾 Detection caching using Pickle for faster re-runs
* 📈 Linear interpolation to recover missed detections
* 🔄 Forward and backward filling for complete trajectories
* 🎯 Smooth visualization with tracking markers
* 📊 Efficient processing pipeline for sports analytics

## 🛠️ Tech Stack

* Python
* Ultralytics YOLO
* OpenCV
* NumPy
* Pandas
* Pickle
* tqdm

## 📂 Project Workflow

1. Load the input video.
2. Detect the ball in each frame using YOLO.
3. Store detections in a cache file for faster future execution.
4. Recover missing detections using linear interpolation.
5. Render the final video with smooth tracking visualization.
